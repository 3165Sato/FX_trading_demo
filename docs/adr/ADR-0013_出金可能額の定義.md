# ADR-0013: 出金可能額を min(残高, 余力) と定義する

- **ステータス**: 採用
- **日付**: 2026-06-28
- **関連**: 指示書「入出金 C11」/ ADR-0011(スワップ未実現方式) / 1b(Equity・余力の算出)

## 背景（なぜ判断が必要だったか）
入出金(C-11)の導入にあたり、建玉保有中に「いくらまで出金してよいか」の定義が必要になった。
残高を全額出金させると、含み損があるときに Equity が必要証拠金を割り、出金が原因でロスカット圏に落ちる。
逆に、含み益や未実現スワップは残高にまだ入っていないため、出金対象にしてはならない。

## 決定（何を選んだか）
```
出金可能額 = min(残高, 余力)      # 余力 = Equity − 必要証拠金合計。マイナスなら 0
```
- Equity が算出不能(レート欠落)のときは出金可能額を算出不能とし、**出金を断る(安全側)**。入金は常に可。
- 出金実行時は口座ロック内で出金可能額を**再計算・再検証**する(検証と実行の間の変動を防ぐ)。

## 理由（なぜそれを選んだか）
- **残高キャップ**: 実現したお金しか出せない(含み益・未実現スワップは未実現。ADR-0011 と整合)。
- **余力キャップ**: 上限まで出金しても Equity ≧ 必要証拠金 が保たれ、
  **出金が原因で維持率100%を割ることが構造的に起きない**(即ロスカット圏行きの事故を防ぐ)。
- 建玉なしのときは 余力=Equity=残高 となり、自然に「全額出金可」に退化する。特別扱いが不要。

## 検討した代替案
- **残高 − 必要証拠金** — 含み損益を見ないため、含み損があるとき出金後に Equity が必要証拠金を割り得る。
- **余力のみ(Equity − 必要証拠金)** — 含み益が大きいと残高以上の出金を許してしまう(未実現利益の引き出し)。
- **残高全額(制限なし)** — 証拠金取引の前提が崩れる。学習デモでも不適切。

## 結果（トレードオフ・影響）
- 含み損があるときは出金可能額が余力まで絞られる(ユーザーには「残高があるのに出せない」と見えるが、
  それこそが証拠金取引の学習ポイントとして表示で説明する)。
- 口座サマリに withdrawable を追加し、余力の表示と整合させる。
- 将来の口座間振替(C-15)・出金審査等も、この出金可能額を上限として再利用できる。
